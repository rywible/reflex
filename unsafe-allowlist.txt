# Reflex unsafe-code allowlist (P0.1: "deny unsafe by default").
#
# Reflex forbids `unsafe` in all owned source by default. Any `unsafe`
# occurrence found by scripts/check-unsafe.sh must be justified here, one
# entry per line, with the format:
#
#   <path>:<line>: <owner crate> — <rationale> — <expiry task/date>
#
# Entries without an owner and rationale are rejected by policy review
# (docs/security/dependency-policy.md). Keep this list empty unless a
# genuine kernel-level justification exists; prefer `#![forbid(unsafe_code)]`
# and safe abstractions instead.
