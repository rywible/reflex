# Require causal success before Wrela

Before Wrela integration, the `u8` Reference Domain must show on untouched Seeds and equal CPU and memory budgets that learned Reflex outperforms its own non-learned search baseline under a preregistered multiobjective analysis. Separate ablations must establish contributions from cross-Seed knowledge, learned allocation, and Derived Operators, while bundle export and restart must reproduce accepted Artifacts and resume improvement.

## Considered Options

A single impressive optimized expression would be easy to communicate but would not demonstrate learning, transfer, autonomy, or causal benefit from Reflex's subsystems. Waiting for a Wrela end-to-end win would entangle validation of the engine with application integration effects.
