# Replay Candidate features without reverification

CPU model representation and size experiments use the non-default, repository-only `internal-experiments` feature. The fixed-Experience analyzer decodes a completed Domain Bundle through normal compatibility and integrity validation, reconstructs structural summaries from canonical parent and Candidate Artifacts, and trains paired models with identical verdicts, consequences, correctness-claim roles, example order, FTRL hyperparameters, and epochs. It never invokes the Verification Kernel for a new label and refuses the comparison unless retraining the baseline features reproduces the persisted champion exactly.

Generating another training campaign for each feature family would waste CPU on identical kernel labels and could silently change the data paired between treatments. Moving experimental controls into the public Session or Domain Definition protocols would leak repository rigor into consumer interfaces. The feature-gated seam keeps the production path deep and unchanged while making the scientific pairing executable. Its structural pass is measured separately from model training so a representation cannot win on predictive loss while hiding prohibitive extraction cost.
