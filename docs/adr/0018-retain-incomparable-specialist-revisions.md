# Retain incomparable Specialist Revisions

Operational Promotion does not reduce revision quality to one scalar. A challenger becomes the default only with sufficient evidence that it improves targeted Measurements without exceeding protected regression tolerances; a useful but incomparable challenger is retained as a Specialist Revision that Campaign construction may select when its strengths fit the Optimization Goals.

## Considered Options

Forcing every challenger into a single total order would erase meaningful trade-offs. Keeping only one default would discard useful specialization, while automatically replacing it after any isolated gain would allow regressions to compound through later Campaigns.
