# Require Verified Seeds for optimization

Every Optimization Run begins from a Seed that is already a Verified Artifact; Reflex searches for verified replacements rather than the first witness for a formal specification. This preserves a precise Seed-relative optimization contract and keeps proof or program synthesis behind a distinct future interface, even though both capabilities may eventually reuse the same search, knowledge, and economic infrastructure.

## Considered Options

Allowing an unsolved proposition or specification to count as a Seed would cover first-proof and first-program discovery through one interface, but it would make optimization and synthesis obey different correctness relationships while appearing to be the same operation.
