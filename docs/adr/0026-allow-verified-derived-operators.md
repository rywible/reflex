# Allow verified Derived Operators

Knowledge Consolidation may turn verified derivations into reusable Derived Operators, expanding the search vocabulary beyond the primitive Operators supplied by the domain. Derived Operators accelerate and abstract candidate proposal, but every result remains subject to the pinned Verification Kernel.

## Considered Options

A permanently fixed operator vocabulary would bound implementation risk but cap Reflex's ability to learn better moves and compress repeated discoveries. Executing unconstrained model-generated transformations would expand the vocabulary faster but move learned behavior inside the correctness trust boundary.
