# Build a production Reference Domain before Wrela

The first domain is a self-contained `u8` expression-superoptimization Reference Domain with no Wrela coupling and no alternative toy interfaces. It exercises the real Domain Definition contract, exhaustive equivalence, multiple Measurements, multi-goal Campaigns, learned allocation, Derived Operators, Knowledge Consolidation, Operational Promotion, and restart-complete Domain Bundles; Wrela is the first external integration afterward.

## Considered Options

Integrating Wrela first would provide immediate application relevance but entangle engine design with one graphics stack. A disposable toy could answer narrow algorithm questions faster but would allow shortcuts that fail to establish the production library boundary.
