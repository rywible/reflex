# Gate large campaigns with directional evidence

Before a resource-intensive development Campaign, Reflex requires a private Directional Harness to pass exhaustive transaction schedules, synthetic verified worlds with known causal structure, fixed-Experience diagnostics, BitVec microcampaigns, and a tiny domain-native smoke run through the same production seams. These gates are designed to falsify mechanics, recovery, causal attribution, and architecture cheaply; only a previously frozen equal-budget real Campaign can support a substantive capability claim.

## Consequences

A large Campaign must reserve host CPU and memory outside its Resource Envelope and cannot begin without a matching passed confidence receipt. The receipt content-addresses the complete Git-visible source snapshot: every tracked or untracked source path, normalized executable mode, symlink target or file contents, and tracked deletion. It then drops capabilities, enables `no_new_privs`, and applies a non-relaxable Landlock policy before any gate exists. This makes the execution bytes unreachable to an external same-UID writer and prevents a gate from reversing the read-only mount or escaping through another user namespace. Source symlinks fail closed. The original checkout must retain the registered identity through receipt publication. The receipt also binds the sealed Cargo/tool identities, exact allowlisted environment, private filesystem bounds, target directory, canonical gate plan, per-gate timeouts, resident limits, and global deadline. A successful receipt is internally consistent: every gate exited successfully without a timeout, resident-limit breach, or supervisor output-limit breach, and the whole run completed within the global deadline.
