# Keep the domain contract thin

A Domain Definition must provide a semantic identity, Artifact representation, reproducible Seed Sources, primitive Operators, a Verification Kernel, and typed Measurements. Goal templates and specialized feature channels are optional accelerators; Reflex owns Campaign construction, search, learning, resource allocation, consolidation, promotion, and persistence so domain authors do not have to rebuild the autonomous stack.

## Considered Options

An opaque callback adapter would be easy to implement but deny Reflex the structure needed to learn and operate autonomously. Requiring each domain to implement search and training hooks would preserve specialization at the cost of turning Reflex into a framework shell rather than a working optimizer.
