# Bound the live knowledge working set

The Resource Envelope bounds active in-memory indexes rather than requiring every historical Artifact, attempt, and inactive Operator to remain hot forever. Knowledge Consolidation may remove redundant material from active indexes and compact cold history, while durable provenance, replay-critical evidence, surviving Verification Records, and evidence required by experimental claims remain recoverable.

## Considered Options

Keeping all history live would maximize immediate access but make autonomous operation eventually violate any finite memory envelope. Destructive pruning would hold memory flat but could invalidate trust, replay, and later credit attribution.
