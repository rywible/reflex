The predeclared structural-16 representation does not pass the paired retained-Experience gate. It must not replace baseline-16, and larger models remain locked.

## Interpretation

The structural family added real signal for downstream potential, so structure is useful. Its four signed operator buckets simultaneously halved the baseline's eight operator distinctions. That loss of operator identity is the clearest representation-level explanation for the broad correctness/value regression. The next same-capacity treatment retains eight stable operator buckets and uses the seven remaining non-bias dimensions for log node size and ratio, Candidate depth and depth ratio, constructor-histogram distance, and root-constructor equality. This is continued Development on the same Selection corpus, not an independent confirmation result.
