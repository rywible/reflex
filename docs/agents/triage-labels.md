# Triage Labels

| Canonical role    | Repository label  | Meaning                                 |
| ----------------- | ----------------- | --------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer must evaluate the issue      |
| `needs-info`      | `needs-info`      | Waiting for information                 |
| `ready-for-agent` | `ready-for-agent` | Fully specified for an autonomous agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation           |
| `wontfix`         | `wontfix`         | Will not be actioned                    |

When a skill names a canonical triage role, use its corresponding repository label.
